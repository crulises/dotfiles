# Setup
For these to work the repository should have been cloned into `~/.config`.

```bash
ln -s ~/.bashrc ~/.config/bashrc/bashrc
```

```bash
ln -s ~/.bash_profile ~/.config/bashrc/bash_profile
```

```bash
ln -s ~/.bash_aliases ~/.config/bashrc/bash_aliases
```

# Helper functions
The `bash_helperfns` file encapsulates definitions of several utilities that might come handy
in another bash-script or in the terminal itself.
